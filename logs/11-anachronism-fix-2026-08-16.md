# 11. 1358년 시대 고증 수정 작업 (2026-08-16)

`logs/10-anachronism-review-2026-08-16.md`의 판정을 실제 코드·배경 이미지에 반영한 기록이다. 10번 문서는 수정 전 감사 스냅샷으로 보존하고, 본 문서를 그 미결 항목에 대한 최종 처리 결과로 삼는다.

## 적용 기준

- 사용자 제공 설정인 **1358년, 14세기 중반 서유럽풍 중세 판타지**를 기준으로 한다.
- 다락 암호의 정본 문구 `"첫째는 멈춘 시간 뒤"`는 유지한다.
- 1358년에 맞지 않는 휴대용 기계식 시계류를 제거하되, 퍼즐의 `정상 작동 / 멈춤 / 파손` 구별 구조는 유지한다.
- 벌목 도구는 원형 회전톱이 아니라 나무틀에 맨 틀톱, 곧은 손톱, 2인용 긴 톱으로 한정한다.

## 코드 및 퍼즐 텍스트 수정

| 수정 전 | 수정 후 | 설계 기능 |
|---|---|---|
| `멈춘 회중시계` | `습기로 모래가 엉겨 멈춘 모래시계` | △ 정답. 유리는 온전하지만 모래가 흐르지 않음 |
| `낡은 손목시계` | `흐르는 모래시계` | Wing 디코이. 마른 모래가 계속 흘러 정답이 아님 |
| `고장 난 탁상시계` | `깨진 모래시계` | 2F 디코이. 유리가 깨지고 모래가 쏟아져 정답이 아님 |
| `삐걱이는 서랍`/쇠사슬 반짝임 | `습기 밴 모래 자국`/엉긴 모래 | △ 힌트. 정답의 상태를 먼저 관찰하게 함 |
| 모호한 `톱날 정리대` | `틀톱 정리대` | 원형 톱으로 해석될 여지를 제거 |

내부 action/flag id(`wing.clockDecoy`, `b2.clockDecoy`, `b2.watchHint` 등)는 기존 저장 데이터와 테스트 호환성을 위해 유지했다. 플레이어에게 노출되는 label·대사와 배경 이미지만 고증에 맞게 교체했다.

## 이미지 수정

built-in imagegen의 `precise-object-edit` 방식으로 기존 구도·벽·포탈·가구 배치를 보존하면서 다음 세 장을 제작했다.

- `cabin-b1-v3.png`: 손목시계·장식용 장시계를 제거하고 흐르는 모래시계로 교체.
- `cabin-b1-rear-v3.png`: 모든 원형 톱날을 틀톱·직선 손톱·2인용 긴 톱으로 교체.
- `cabin-b2-v3.png`: 회중시계·탁상시계를 제거하고, 습기로 멈춘 온전한 모래시계와 깨져 모래가 쏟아진 디코이 모래시계를 분리 배치.

`public/assets/manifest.json`의 `bg.cabinB1`, `bg.cabinB1Rear`, `bg.cabinB2`는 모두 `v3`를 가리킨다.
