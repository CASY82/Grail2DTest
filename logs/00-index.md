## 총평

GR-1의 **진행 골격(비트 시트 순서·플래그 체인·퍼즐 보상 구성)은 정본과 거의 1:1로 일치**한다. 특히 문서 0.1의 정합성 보정(다락 서랍 = 녹슨 열쇠 + 경고 쪽지 + △ 진실 조각)과 3.3의 진입 단서 문구("뒤편 울타리 → 벼락 맞은 참나무 → 얕은 개울 → 옛 수레길")는 원문 그대로 반영돼 있고, 레이어드 구조도 확장에 유리하다. 다만 **이 프로토타입이 검증하겠다고 선언한 것(문서 6.3 제작 우선순위 1번: "상태 변화·수직 탐색·그림자 퍼즐·첫 추격·공포 톤")을 실제로는 절반만 검증하고 있다** — 걷기/앉기/등잔은 HUD 숫자로만 존재하고 어떤 AI도 그 값을 읽지 않으며(`ChaseService.ts:11`이 유일한 소비처, 효과는 +8%), 첫 오두막의 "상태 변화"는 인터랙션 2개의 표시/숨김일 뿐 공간이 시각적으로 변하지 않고, 클라이맥스인 첫 Hollow 추격은 문서의 20~35초 대비 **실측 5.4초**(달리기 기준, 아래 03 문서 참조)에 끝난다.

더 심각한 것은 두 개의 **논리 결함**이다. 첫째, 숲 → 관문 포털에 선행 플래그가 없어(`Chapter1World.ts:29`) 플레이어가 관문을 먼저 확인하면 첫 오두막을 **단 한 번만 방문하고 양피지와 관리 기록을 동시에 읽을 수 있다** — 문서 00장이 v1에서 v2로 바꾼 바로 그 핵심 루프("첫 방문 → 관문 확인 → 재방문 상태 변화")가 통째로 무력화된다. 둘째, 그림자 퍼즐의 정답 각도(거울 45°/촛대 30°)에 대한 인게임 단서가 **어디에도 없고**, 수색 암호에서 순서를 지정하는 서수("첫째/둘째/마지막")가 삭제되어(`Chapter1FlowService.ts:39`) 문서 6.4의 Done 기준 "문서와 환경 단서의 추론 논리가 유지된다"를 만족하지 못한다. 현재 이 퍼즐은 추론이 아니라 1회 실패 후 정답을 통보받는 구조다(`ModalView.ts:48`).

프로토타입 단계 기준으로 **체력·정신력·횃불·늑대·A*·LOS 미구현은 정상 범위**이며 이 감사는 그것을 문제로 부풀리지 않는다. 그러나 위 두 논리 결함과 "소음 시스템이 게임플레이에 영향이 0"이라는 사실은 프로토타입의 존재 이유(수치·루프 검증) 자체를 훼손하므로 **정상 범위 밖의 P0**로 판단한다. 에셋은 12개 논리 ID 전부가 660바이트급 그라디언트 placeholder이고, docx 내부에 실제 컨셉아트 25장(`word/media/`)이 미사용 상태로 들어 있다 — 이건 갭이라기보다 **아직 수행되지 않은 반입 작업**이다.

한 줄 결론: **구조는 살려두고, 스펙 수치와 게이팅 논리부터 붙여라.** 새 기능(정신력·횃불)보다 이미 만든 시스템(소음·등잔·추격·퍼즐)을 문서 수치에 연결하는 작업이 먼저다.

## 감사 방법론

1. **정본 추출**: `python-docx`/`pandoc` 미설치 환경이므로 표준 라이브러리만으로 `Grail_Chapter_Level_Design_v2_latest.docx`를 `zipfile`로 열어 `word/document.xml`을 `xml.etree.ElementTree`로 파싱, 문단(`w:p`)과 표(`w:tbl`)를 순서대로 텍스트화했다(전 챕터 389행). 이미지 목록은 `zipfile.namelist()`로 `word/media/*` 25개를 확인했다.
2. **소스 전수 통독**: `src/` 하위 TypeScript 15개 파일, `config/Chapter1World.ts`, `index.html`, `style.css`, `server.mjs`, `tests/smoke.mjs`, `public/assets/manifest.json` 및 SVG 12개 전량을 읽고, `dist/`가 `src/`와 동기 상태임을 확인했다.
3. **수치 검증**: 주장에 계산이 필요한 항목은 실측했다. 추격 구간 최단 경로는 `chaseRoad`의 벽 데이터와 플레이어 히트박스(28×36px)로 8방향 다익스트라를 돌려 **1288.6px**을 얻었고, 이를 이동 속도(88/146/238px/s)로 나눠 소요 시간을 산출했다.
4. **표기 원칙**: 근거는 `파일:라인` 또는 docx 원문 인용으로 명시하고, 계산·해석이 개입한 판단은 **추정**이라고 표시했다.
